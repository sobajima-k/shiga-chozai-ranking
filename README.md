# 滋賀 調剤基本料ランキング

滋賀県の保険薬局681件を、施設基準の届出と令和8年6月改定の調剤報酬点数から、処方箋1回あたりの点数で並べた一覧です。

公開ページ：https://sobajima-k.github.io/shiga-chozai-ranking/

## 計算方法

- **処方箋1回あたり**：調剤基本料＋地域支援・医薬品供給対応体制加算＋連携強化加算＋調剤ベースアップ評価料
- **全施設基準合計**：届出している全項目の点数の単純合計（算定頻度は考慮しない目安）
- 詳しい前提はページ下部の「点数の計算方法」に記載しています。

## 出典

- 滋賀県 届出受理医療機関名簿（薬局）令和8年11月1日現在
- 日本薬剤師会「調剤報酬点数表（令和8年6月1日施行）」令和8年3月31日作成
